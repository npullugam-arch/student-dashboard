Help & Support • FAQs
Go to Assignments → choose the subject → open the assignment → click Upload / Submit.
  • Attach your file(s) (PDF/DOC/Images as allowed).
  • Check the deadline and instructions before submitting.
  • After submission, confirm the status shows Submitted.
Go to Academics → Attendance.
  • View day-wise and subject-wise attendance.
  • Use filters (month/subject) to find specific records.
  • If something looks wrong, raise a request via Contact Support.
Go to Examination → Results.
  • Select the exam/term to view marks and grade details.
  • Download the report if your portal supports it.
  • If results aren’t visible, wait for the official publish time.
Go to Diary or Academics → Leave Application (based on your menu).
  • Select leave dates and mention a clear reason.
  • Attach proof if required (medical note, event letter).
  • Track approval status under Leave History.

  • Select the teacher and write a short, respectful message.

Open Assignments → select the assignment → check for Edit Submission / Resubmit.
  • If resubmission is allowed, replace the file and submit again.
  • If not allowed, contact your teacher or support before the deadline.
Try these quick fixes:
  • Check file size and format limits (PDF/DOC/JPG, etc.).
  • Rename the file (avoid special characters like #, %, &).
  • Switch network or retry after refreshing the page.
  • If it still fails, share a screenshot via Contact Support.
Go to Time Table.
  • Use day/week view to check lecture timings.
  • Verify room/online link details if provided.
  • If a class is missing, report it to your coordinator.
Go to Examination → Schedule.
  • Check subject, date, time, and venue.
  • Download/print the schedule if available.
  • Monitor notifications for last-minute changes.
Go to Payments → choose the fee type → proceed to payment.
  • After success, download the receipt from Payment History.
  • If money is deducted but status is pending, wait a while and refresh.
  • If it doesn’t update, contact support with transaction details.
Use Forgot Password on the login page (or Profile → Security if available).
  • Verify OTP sent to your registered email/phone.
  • Create a strong password (mix letters, numbers, symbols).
  • Log out and log in again to confirm changes.
Go to Profile (top-right avatar) → Edit Profile.
  • Update allowed fields (address, guardian details, etc.).
  • Some fields may be locked—request changes via support if needed.
Go to Notifications → Settings (if available).
  • Enable alerts for assignments, exams, and announcements.
  • Check that your email/phone is correct in your profile.
  • Whitelist portal emails to prevent spam filtering.
Go to Bus Tracking.
  • Choose your route to view live location (if enabled).
  • ETAs depend on traffic and GPS signal strength.
  • If tracking is unavailable, it may be turned off outside route timings.
Raise a request as soon as possible:
  • Take a screenshot of the issue.
  • Message your subject teacher (or class teacher).
  • If unresolved, submit via Contact Support with details (date/subject/exam).
